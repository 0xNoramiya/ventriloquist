# Pictograms

Generated for this project with Muse Image (`muse-image-1.0`) by `scripts/generate_pictograms.py`:
one per taxonomy message, 256 px WebP, each reviewed by eye on a contact sheet. Picture symbols are
standard on AAC boards; they help patients with low vision, limited literacy or fatigue recognise a
message at a glance. Each file is named after its taxonomy id (`see_person.webp` is used for every
family member).
